# Integrated library LLM / RAG

Authority: the user requests a working official LLM/RAG pipeline; AGENTS.md delegates routine decisions and continuous implementation. Library-only scope, local Ollama/FastEmbed/Qdrant, no paid calls, no production deployment. Existing source review/editor is the ingestion boundary; no automatic publication of crawled text. No training from scratch or framework rewrite.

Approach: extend existing retrieval rather than add a second stack. Preserve direct strong FAQ answers and structured catalog/policy routes. For other questions, combine lexical and chunk semantic retrieval, pass bounded complete excerpts to the existing citation-checked model and recheck original source rows before responding. Use existing admin interface for operational checks rather than a separate app.
